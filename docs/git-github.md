\# Git \& GitHub Command Reference



| Commands | Purposes |

| :--- | :--- |

| `git init` | Initialize a new local Git repository |

| `git config --global user.name "Name"` | Configure commit author name |

| `git status` | View modified, staged, and untracked files |

| `git add <file>` / `git add .` | Stage files for commit |

| `git commit -m "Message"` | Record staged changes in repository history |

| `git log --oneline` | Display commit history |

| `git diff` | Inspect unstaged line-by-line changes |

| `git branch <name>` | Create a new branch |

| `git checkout -b <name>` | Create and switch to a new branch |

| `git merge <branch>` | Merge specified branch into current branch |

| `git remote add origin <url>` | Link local repository to a GitHub remote |

| `git push -u origin main` | Push local commits to GitHub |

| `git pull` | Fetch and merge remote changes |

| `git clone <url>` | Clone an existing remote repository |
