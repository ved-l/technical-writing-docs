\# Google Docs Documentation



Google Docs is a cloud-based word processor in Google Workspace designed for real-time collaborative authoring and rapid document creation.



\## Core Features

\* \*\*Real-Time Collaboration:\*\* Share documents with View, Comment, or Edit permissions, and use \*\*Suggesting\*\* mode for tracked edits.

\* \*\*Paragraph Styles \& Hierarchy:\*\* Apply `Title`, `Subtitle`, `Heading 1`, and `Normal Text` styles to auto-generate a Table of Contents.

\* \*\*Version History:\*\* Use `File -> Version history` to inspect previous states, name milestone versions, or restore earlier drafts.

\* \*\*Diagrams, Equations \& Citations:\*\* Insert shapes/diagrams via `Insert -> Drawing`, LaTeX-style math via `Insert -> Equation`, and MLA/APA/Chicago bibliographies via `Tools -> Citations`.



\## Doxygen vs. Google Docs

| Feature | Doxygen | Google Docs |

| :--- | :--- | :--- |

| \*\*Purpose\*\* | Code \& API Reference Manuals | General Docs, Proposals \& Notes |

| \*\*Collaboration\*\* | Indirect via Git \& code reviews | Real-time multi-user editing |

| \*\*Rich Media\*\* | Diagrams generated from code | Images, tables, drawings |

| \*\*Output\*\* | HTML, LaTeX, PDF, RTF, XML | Web, PDF, DOCX, ODT, HTML |

| \*\*Best For\*\* | Source code \& software libraries | Policies, specifications, team docs |
